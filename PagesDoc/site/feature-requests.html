الاقتراح يصل إلى مطوّر النظام، لا إلى مالك منشأتك. لطلب صلاحية أو تعديل بيانات داخل منشأتك، تواصل مع مدير النظام عندكم.

قبل البدء#

  • حساب GitHub مجاني: يُرسل الطلب باسم حسابك. إن لم يكن لديك حساب فأنشئه من github.com/signup.
  • أي مستخدم يستطيع الإرسال: الصفحة متاحة لكل من يدخل النظام، ولا تحتاج صلاحية خاصة.
  • الطلبات على GitHub عامة يراها الجميع: لا تكتب فيها أسماء عملاء أو مبالغ أو أي بيانات خاصة بمنشأتك.

1افتح صفحة «طلبات المميزات»#

افتحها بإحدى هذه الطرق:

من أين؟ ماذا تضغط
القائمة الجانبية التحديثات والطلبات ← طلبات المميزات
زر «عرض» أعلى الشاشة طلبات المميزات
صفحة «أبرز التحديثات» زر «طلبات المميزات» أعلى الصفحة
شريط العنوان في المتصفح عنوان النظام وبعده /feature-requests، مثل http://localhost:8000/feature-requests على جهاز المكتب

2اكتب طلبك#

هكذا تبدو الصفحة في النظام (البيانات للتوضيح فقط):

طلب ميزة أو تحسينيصل طلبك إلى مطوّر النظام مباشرة على GitHub
أبرز التحديثاتالطلبات المفتوحة والتصويت
نوع الطلب *ميزة جديدة
الشاشة أو القسمفواتير المبيعاتمثل: فواتير المبيعات، الرواتب
عنوان الطلب *تذكير العميل تلقائياً قبل موعد استحقاق الفاتورة
الوصف *أريد أن يرسل النظام رسالة تذكير للعميل قبل موعد الاستحقاق بثلاثة أيام، لأننا نتابع ذلك يدوياً اليوم وتفوتنا فواتير كثيرة.ما الذي تريده، ولماذا، وكيف تتخيل عمله؟

عند الإرسال تُفتح صفحة GitHub بالطلب جاهزًا لتراجعه وتؤكد إرساله بحسابك (يلزم حساب GitHub مجاني). يمكن للآخرين التصويت عليه بـ 👍.

إرسال إلى المطوّر عبر GitHub

املأ الحقول:

الحقل ماذا تكتب
نوع الطلب (إلزامي) «ميزة جديدة»، أو «تحسين على ميزة قائمة».
الشاشة أو القسم مكان الطلب في النظام، مثل: فواتير المبيعات، أو الرواتب.
عنوان الطلب (إلزامي) جملة قصيرة تلخّص ما تريد، حتى 200 حرف.
الوصف (إلزامي) ما الذي تريده، ولماذا، وكيف تتخيّل عمله؟

ثم اضغط «إرسال إلى المطوّر عبر GitHub».

3راجع الطلب في GitHub وأرسله#

تُفتح صفحة GitHub في تبويب جديد، وفيها طلبك جاهزاً:

  1. إن طُلب منك الدخول: ادخل بحسابك في GitHub، أو أنشئ حساباً مجانياً.
  2. راجع العنوان والوصف. يضيف النظام إلى الوصف تلقائياً نوع الطلب والشاشة ورقم إصدار «الديوان» الذي تستخدمه.
  3. أرفق صورة إن أردت: اسحب صورة الشاشة إلى مربع الوصف.
  4. اضغط Create (أو Submit new issue) لإرسال الطلب.

لا يُرسل شيء قبل أن تضغط زر GitHub. النظام لا يحفظ أي كلمة مرور أو رمز لـ GitHub، ولا يُرسل شيئاً من بيانات منشأتك: الطلب يحتوي ما كتبته ورقم الإصدار فقط.

هذا شكل الوصف الذي يصل إلى GitHub:

Markdown
**النوع:** ميزة جديدة
**الشاشة أو القسم:** فواتير المبيعات
**إصدار الديوان:** 1.5.0

أريد أن يرسل النظام رسالة تذكير للعميل قبل موعد الاستحقاق بثلاثة أيام...

بعد الإرسال#

  • المتابعة: يظهر طلبك في قائمة طلبات المشروع، ويصلك بريد من GitHub عند أي رد عليه.
  • التصويت: يصوّت المستخدمون على الطلبات بـ 👍، فيعرف المطوّر أكثرها أهمية. ابحث في القائمة قبل أن تكتب طلباً جديداً: إن وجدت طلبك فصوّت عليه بدل تكراره.
  • عند التنفيذ: تصل الميزة في إصدار جديد إلى نسختك مع التحديث التلقائي، وتظهر في صفحة «أبرز التحديثات» داخل النظام، وعليها نقطة حمراء في القائمة حتى تقرأها.

نصائح لاقتراح واضح#

  • طلب واحد في كل مرة: فكرتان في طلب واحد يصعب تنفيذهما ومتابعتهما.
  • ابدأ بالمشكلة: ما الذي يصعب عليك اليوم؟ ثم اقترح الحل.
  • كن محدداً: اذكر الشاشة، والخطوات التي تقوم بها الآن، والنتيجة التي تريدها.
  • اختر عنواناً يصف الطلب: «تذكير العميل قبل موعد الاستحقاق» أوضح من «اقتراح» أو «مهم جداً».

الإبلاغ عن خطأ#

صفحة «طلبات المميزات» للأفكار والتحسينات. إن ظهر لك خطأ، أو توقف شيء عن العمل:

  1. صوّر الشاشة التي ظهر فيها الخطأ.
  2. افتح طلباً جديداً في صفحة المشروع مباشرة.
  3. اكتب ما كنت تفعله قبل الخطأ، ورقم إصدار «الديوان» (يظهر أعلى صفحة «أبرز التحديثات»)، وأرفق الصورة.

حل المشكلات#

المشكلة الحل
لم تُفتح صفحة GitHub بعد الضغط على الزر المتصفح منع فتح نافذة جديدة. اسمح بالنوافذ المنبثقة لعنوان النظام، ثم اضغط الزر مرة أخرى.
GitHub يطلب تسجيل الدخول الإرسال يحتاج حساباً في GitHub. ادخل أو أنشئ حساباً مجانياً. إن وجدت الطلب فارغاً بعد الدخول، فارجع إلى «طلبات المميزات» واضغط الإرسال من جديد.
ظهر خطأ في GitHub والوصف طويل جداً نص الطلب يُنقل إلى GitHub داخل الرابط، وللرابط حد أقصى. اختصر الوصف في النظام، وأكمل التفاصيل في GitHub قبل الإرسال.
لا أجد «طلبات المميزات» في القائمة افتح مجموعة «التحديثات والطلبات» في آخر القائمة الجانبية، أو استعمل زر «عرض» أعلى الشاشة.
