# تثبيت «الديوان» على ويندوز

دليل خطوة بخطوة لتثبيت النظام على جهاز ويندوز 10 أو 11، حتى لو كان الجهاز جديداً ولا يحتوي أي برنامج. لا تحتاج أي خبرة تقنية. يستغرق التثبيت 10-20 دقيقة، معظمها تنزيل.

## قبل البدء

- جهاز ويندوز 10 أو 11، وفيه 3 جيجابايت فارغة على الأقل في القرص `C:`.
- اتصال بالإنترنت.
- حساب ويندوز بصلاحية **مدير** (Administrator). غالباً حسابك كذلك إن كنت أنت من أعد الجهاز.
- اختر الجهاز الذي سيبقى **مشغّلاً طوال وقت العمل**، لأن بقية أجهزة المكتب تتصل به.

## الخطوة 1: نزّل ملف التثبيت

افتح هذا الرابط في المتصفح:

**https://github.com/turkialawlqy/Diwan-ERP/releases/latest/download/Diwan-Setup.bat**

سيُنزَّل ملف صغير اسمه `Diwan-Setup.bat` إلى مجلد **التنزيلات** (Downloads).

> إن سألك المتصفح «هل تريد الاحتفاظ بهذا الملف؟» اختر **احتفاظ** (Keep).

## الخطوة 2: شغّل الملف

1. افتح مجلد **التنزيلات** وانقر نقراً مزدوجاً على `Diwan-Setup.bat`.
2. **قد تظهر شاشة زرقاء** عنوانها «Windows protected your PC» (حماية ويندوز). هذا طبيعي لأي ملف جديد غير موقّع تجارياً:
   - اضغط على **More info** (مزيد من المعلومات).
   - ثم اضغط **Run anyway** (تشغيل على أي حال).
3. **سيسألك ويندوز:** «هل تريد السماح لهذا التطبيق بإجراء تغييرات على جهازك؟». اضغط **نعم** (Yes).

## الخطوة 3: انتظر حتى ينتهي

تفتح نافذة سوداء وتظهر فيها خطوات التثبيت بالإنجليزية (لأن هذه النافذة لا تعرض العربية جيداً). **لا تغلقها**، واتركها حتى تنتهي.

| ما يظهر | معناه |
|---|---|
| `[1/9] Checking this computer` | فحص نظام التشغيل والمساحة الفارغة. |
| `[2/9] Microsoft Visual C++ runtime` | برنامج صغير من مايكروسوفت يحتاجه PHP. |
| `[3/9] PHP 8.3` | تنزيل PHP، اللغة التي كُتب بها النظام. |
| `[4/9] Database (MariaDB)` | تنزيل قاعدة البيانات وتشغيلها كخدمة. |
| `[5/9] Downloading the latest Diwan release` | تنزيل النظام نفسه (نحو 100 ميجابايت). |
| `[6/9] Settings and database tables` | تجهيز الإعدادات وجداول البيانات. |
| `[7/9] Starting Diwan automatically with Windows` | ضبط التشغيل التلقائي مع ويندوز. |
| `[8/9] Allowing the office devices to connect` | السماح لأجهزة المكتب بالوصول. |
| `[9/9] Shortcuts` | إنشاء الاختصارات. |
| `Installed successfully!` | **تم التثبيت بنجاح.** |

إن ظهر **`ERROR`** باللون الأحمر، انظر [حل المشكلات](#حل-المشكلات) في آخر الدليل.

## الخطوة 4: الإعداد الأول

بعد النجاح يفتح المتصفح تلقائياً على صفحة **«تم تثبيت النظام بنجاح»**. اكتب فيها:

1. **اسم المنشأة**، و**الدولة**، و**العملة**. انتبه: العملة لا يمكن تغييرها بعد البدء.
2. **حساب المدير:** الاسم، والبريد الإلكتروني، وكلمة المرور. البريد هو اسم الدخول، ولا يحتاج تأكيداً.
3. اضغط **«ابدأ استخدام النظام»**.

تدخل إلى لوحة التحكم مباشرة. **احفظ البريد وكلمة المرور.** هذه الصفحة لا تظهر مرة أخرى.

## فتح النظام بعد ذلك

- **من هذا الجهاز:** انقر نقراً مزدوجاً على اختصار **«الديوان»** على سطح المكتب، أو افتح `http://localhost:8000`.
- **من أجهزة المكتب الأخرى والجوالات:**
  1. في النظام افتح **الإعدادات**. ستجد مربع **«الوصول من أجهزة المكتب»**، وفيه العنوان، مثل `http://192.168.1.20:8000`، ورمز QR.
  2. اكتب العنوان في متصفح أي جهاز متصل **بنفس الراوتر**، أو امسح الرمز بكاميرا الجوال.
  3. أضف لكل موظف حساباً من **الإعدادات ← المستخدمين**.

> **النظام يعمل تلقائياً** مع كل تشغيل للجهاز، حتى قبل تسجيل الدخول إلى ويندوز. لا تحتاج تشغيله يدوياً.

## الأدوات في قائمة ابدأ

افتح **قائمة ابدأ ← الديوان**:

| الأداة | متى تستخدمها |
|---|---|
| **فتح الديوان** | يفتح النظام في المتصفح. |
| **تحديث الديوان** | يحدّث فوراً بدلاً من انتظار التحديث الليلي. |
| **نسخة احتياطية الآن** | قبل أي عمل كبير، أو قبل نقل الجهاز. |
| **إعادة تشغيل الديوان** | إن توقف النظام عن الاستجابة، أو بعد تعديل الإعدادات. |
| **إلغاء تثبيت الديوان** | يزيل النظام، ويسألك هل تحتفظ ببياناتك. |

كل أداة تطلب صلاحية المدير: اضغط **نعم**.

## أماكن الملفات

| المجلد أو الملف | المحتوى |
|---|---|
| `C:\Diwan\secrets.txt` | **كلمات المرور.** انسخه إلى فلاش أو بريدك واحتفظ به. |
| `C:\Diwan\shared\storage\app\backups\` | **النسخ الاحتياطية الليلية.** انسخها أسبوعياً إلى فلاش أو تخزين سحابي. |
| `C:\Diwan\shared\.env` | الإعدادات، مثل البريد. |
| `C:\Diwan\data\` | قاعدة البيانات (لا تعدّل فيها يدوياً). |
| `C:\Diwan\logs\` | سجلات التشغيل والتحديث. |

## إرسال الفواتير بالبريد (اختياري)

لإرسال الفواتير وكشوف الحساب إلى العملاء بالبريد:

1. افتح الملف `C:\Diwan\shared\.env` بالمفكرة (Notepad): زر يمين ← فتح باستخدام ← Notepad.
2. عدّل هذه الأسطر ببيانات بريدك (من مزود البريد، مثل Zoho أو Gmail):
   ```
   MAIL_MAILER=smtp
   MAIL_HOST=smtp.zoho.com
   MAIL_PORT=587
   MAIL_USERNAME=invoices@your-company.com
   MAIL_PASSWORD=كلمة-مرور-البريد
   MAIL_FROM_ADDRESS=invoices@your-company.com
   ```
3. احفظ الملف، ثم شغّل **قائمة ابدأ ← الديوان ← إعادة تشغيل الديوان**.

## النقل إلى جهاز جديد

1. على الجهاز القديم: **نسخة احتياطية الآن**، ثم انسخ إلى فلاش:
   - مجلد `C:\Diwan\shared\storage\app\backups\`؛
   - الملف `C:\Diwan\secrets.txt`.
2. على الجهاز الجديد:
   - ثبّت النظام بهذا الدليل.
   - **لا تكمل صفحة الإعداد الأول.**
   - انسخ ملف النسخة الاحتياطية إلى `C:\Diwan\shared\storage\app\backups\`.
3. افتح PowerShell كمدير (زر يمين على ابدأ ← Terminal (Admin)) واكتب:
   ```powershell
   cd C:\Diwan\current
   C:\Diwan\bin\php\php.exe artisan erp:restore اسم-ملف-النسخة.zip
   ```
   تحتاج كلمة `BACKUP_PASSWORD` القديمة من `secrets.txt` القديم. ضعها في `C:\Diwan\shared\.env` قبل الأمر، ثم شغّل «إعادة تشغيل الديوان».

## حل المشكلات

| المشكلة | الحل |
|---|---|
| أغلقت النافذة السوداء فوراً، أو لم يحدث شيء | تأكد أنك ضغطت **نعم** في سؤال الصلاحيات. شغّل الملف مرة أخرى. |
| `Could not download ...` | تحقق من الإنترنت، ثم أعد تشغيل `Diwan-Setup.bat`. إعادة التشغيل آمنة وتكمل من حيث توقفت. |
| `PHP extension missing` أو `Could not install Visual C++` | أعد تشغيل الجهاز، ثم شغّل `Diwan-Setup.bat` مرة أخرى. |
| برنامج مكافحة الفيروسات حذف ملفاً أو منعه | أضف المجلد `C:\Diwan` إلى الاستثناءات في برنامج الحماية، ثم أعد التثبيت. |
| `Diwan did not answer on port 8000` | شغّل «إعادة تشغيل الديوان». إن استمرت المشكلة، أرسل الملف `C:\Diwan\logs\web.log` لطلب المساعدة. |
| أجهزة المكتب لا تفتح العنوان | 1. تأكد أن الجهاز الآخر على **نفس الراوتر**. 2. اجعل الشبكة **خاصة**: الإعدادات ← الشبكة والإنترنت ← Wi-Fi أو Ethernet ← اختر الشبكة ← نوع ملف تعريف الشبكة: **خاص** (Private). 3. استخدم العنوان الظاهر في إعدادات النظام، فقد يتغير بعد إعادة تشغيل الراوتر. |
| النظام لا يفتح بعد إعادة تشغيل الجهاز | انتظر دقيقة بعد التشغيل، ثم جرّب. إن لم يعمل، شغّل «إعادة تشغيل الديوان». |
| نسيت كلمة مرور المدير | من صفحة الدخول اضغط «نسيت كلمة المرور» إن كان البريد مضبوطاً. أو اطلب من مستخدم مدير آخر تغييرها من **الإعدادات ← المستخدمين**. |

لأي مشكلة أخرى: صوّر النافذة وافتح طلباً في [صفحة المشروع](https://github.com/turkialawlqy/Diwan-ERP/issues).

> **ملاحظة لمن ثبّت سابقاً على MAMP أو Laragon:** الطريقة القديمة موثقة في [WINDOWS-LOCAL.md](WINDOWS-LOCAL.md). الطريقة في هذا الدليل أبسط ولا تحتاج أي برنامج مسبق.
